Agent 目录

Hub 知道哪些 agent 定义，以及哪台设备上装好了哪个版本。数据来自心跳的 capabilities.agents，没有第二份存储。 只读聚合：装 agent 是 M5 的流程，托管覆盖层是 M2，都不在本阶段。

◆
这一页没有对话、没有面板、没有时间轴
目录 = 静态聚合。它回答「哪个节点上能用什么」，可枚举、无运行期； 实例离线时目录仍在——「这台设备上装过，但够不着」是一条要保留的事实。
会话 = 有运行期。一次在某个 node、某条路径上的运行，有对话、有轨迹， 断线会冻结成只读（45 秒内是 reconnecting，不冻结）。
所以本页每个定义卡片的唯一动作是「用它开会话」，没有「进入目录」这种动作—— 目录不是一个能进去的地方。
