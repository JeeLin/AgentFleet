Agent 能用的能力，由任务授予

不是默认开放
方式能不能为什么
Agent 直接调用任意连接器 禁止 等于开一条统一提权通道，还要我们替它维护权限
按任务授予「技能」（这个任务可以连 db-prod） 主路径 任务没声明就没有，不是默认能力
设备上起一个 MCP server，Agent 按标准协议连 并行支持 通用接口，支持 MCP 的 Agent 都能用，我们不必为每个 Agent 写适配

凭据不会进 Agent 的上下文：Agent 说「用 db-prod 跑这条 SQL」，凭据由设备侧注入。 每一次连接都进审计轨迹。

管理凭据与授予 这一页只讲原则。加数据库、看谁用过、轮换，都在技能与 MCP 页
