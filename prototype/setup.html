完成首次配置

Hub 处于未初始化状态。它生成了一次性 setup token， 你在浏览器里粘贴它来建立管理凭据。token 只在 15 分钟内有效。

在运行 Hub 的机器上取 token
afcli setup --print-token
它是密码，别贴进聊天工具或截图。
至少 12 位。这是唯一凭据——没有邮箱可找回。
失败态演示（点击切换）

token 不匹配 = 重新 afcli setup --print-token； 已失效被锁 = 等冷却后重跑；Hub 已初始化 = 直接去登录。 三句话三步路，压成一句「setup 失败」用户只能瞎试。
