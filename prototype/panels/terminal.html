尺寸协商（cols×rows）
终端面板的尺寸不是「占满剩余空间」那么简单：浏览器里显示的是 cols×rows， 实际下发给 PTY 的是 cols+1, rows-1（终端最后一行要留给输入提示）。 所以面板头永远显示协商后的尺寸，不是 CSS 算出来的像素。
[PTY] cols=120 rows=37 → 协商 → cols=120 rows=36（输入行占用最后一行）

丢帧、粘贴块、断线不冻结
丢帧 — 输出超出带宽时 Hub 可能丢帧，终端必须显式告知（丢了多少帧）， 而不是让用户以为「这就是全部输出」。终端底部一条 丢帧 ×N 徽标。
可粘贴选择块 — 终端输出里的路径、错误串、命令可以粘贴。 粘贴多行时 Hub 先确认（防止把整个脚本误贴进 shell）。
断线不冻结 — 45 秒内的断线不冻结终端（PTY 在设备上还活着）。 只有判离线才拦输入，并同时说明「设备上它还活着」—— 冻结一个还活着的东西会让用户以为它死了。
